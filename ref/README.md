# 快贝智单（QuickBillMate）

在线开源销售清单生成系统 —— 纯前端、零依赖、即开即用。

## 特性

- **纯前端**：单个 HTML 文件，无需服务器、无需安装、无需构建
- **实时预览**：编辑即所见，修改即时反映到打印预览
- **打印友好**：`@media print` 自动隐藏编辑区域，直接输出专业清单
- **中文大写金额**：自动将合计金额转换为中文大写（壹贰叁肆伍陆柒捌玖）
- **动态商品表格**：支持增删行，灵活编辑商品名称、规格、数量、单价等
- **离线可用**：下载后浏览器直接打开，无需网络

## 快速开始

1. 下载 `index.html`
2. 用浏览器打开
3. 填写信息，编辑商品列表
4. 点击 **打印清单** 或使用浏览器打印功能（Ctrl+P）

## 使用说明

| 区域 | 说明 |
|------|------|
| 编辑区 | 填写公司名称、编号、日期、客户信息、优惠金额等 |
| 商品表格 | 逐行录入商品，支持增删 |
| 预览区 | 实时渲染最终清单样式 |
| 操作按钮 | 刷新预览 / 打印 / 加载示例 / 清空 |

## 技术栈

- HTML5
- CSS3（含打印样式）
- Vanilla JavaScript（无框架、无依赖）
